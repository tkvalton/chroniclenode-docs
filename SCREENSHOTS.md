# Screenshots

Every screenshot the documentation asks for. A page shows a screenshot only when its file exists, so you can add them in any order and push as you go.

## Where they go

Save each picture as a **PNG** in `docs/public/screenshots/`, named exactly as in the *File* column (for example `docs/public/screenshots/abilities-editor.png`). Then commit and push; the site rebuilds in about a minute.

## How to take them

- Use the dark Godot editor theme, and the same window size for all of them (about 1600 pixels wide works well).
- Crop to what the caption names: the editor panel, not the whole screen. For a dialog, crop to the dialog.
- Select a real example so the fields are filled in (the demo content is fine).
- Leave out anything personal: file paths with your user name, the Godot project list.
- A tooltip or highlight is only needed if the caption says so.
