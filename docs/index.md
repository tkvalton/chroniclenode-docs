# Welcome

This is the documentation of **ChronicleNode**, the RPG toolkit for the Godot engine: a set of editors, systems and ready-made content for building role-playing games without writing the common parts yourself.

::: tip
New here? Start with [Getting started](/getting-started/), which installs the addon and walks you through the editor.
:::

## How the documentation is organised

| Section | What is in it |
|---|---|
| [Getting started](/getting-started/) | Install and enable the addon, a tour of the editor |
| [Guide](/guide/) | One chapter per part of the editor: what it is, every field, how it behaves in the game |
| Tutorials | Step by step: build something small, then something bigger |
| Advanced | How the toolkit is built, and how to extend it with your own scripts |
| Reference | Lists you look things up in: text tokens, triggers, actions, settings |
