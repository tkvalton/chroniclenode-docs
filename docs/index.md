# Welcome

This is the documentation of **ChronicleNode**, the RPG toolkit for the Godot engine: a set of editors, systems and ready-made content for building role-playing games without writing the common parts yourself.

::: tip
New here? Start with [General](/general/): it installs the addon and walks you through the editor.
:::

## How the documentation is organised

| Section | For | What is in it |
|---|---|---|
| [General](/general/) | Everyone | Installing the template project or the addon, a tour of the editor |
| [Basic](/basic/) | Anyone building a game | One chapter for each system: what it is, every field of its editors, how it behaves in the game, and tutorials that build something step by step |
| [Advanced](/advanced/) | Developers who write scripts | How the toolkit is built, and how to extend it with your own code |

Each section has its own menu on the left. Inside it, the menu is a tree: the systems first, then the pages of each system.
