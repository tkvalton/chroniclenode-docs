# Localization

::: warning Not built yet
The localization editor is a placeholder and the *Language* setting does nothing yet. The plan for it, with how it will work, is on [Localization (planned)](/planned/localization).
:::

Today only some text can hold more than one language: the text of [conversations](/basic/behaviors/conversations), their voice lines and the hand-in text of a [quest](/basic/events-and-quests/quests) are lists with one entry for each language.
