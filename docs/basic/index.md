# Basic

The basic guide teaches you to use the editor and explains how every system behaves in the game. You never need to open a script.

Two pages are worth reading first: [Keywords](/basic/keywords), the small mechanics that come up everywhere, and [The Database](/basic/database), which explains where everything you make is saved and how things refer to each other.

It has one chapter for each system, in the same order as the editor's categories. A chapter starts with an overview page that explains the idea and how the pieces fit together, then has a page for each of its editors, and then tutorials that build something with it, from a single resource up to more complex ones.
