# AbilityRankFields

**Inherits:** [VBoxContainer](https://docs.godotengine.org/en/stable/classes/class_vboxcontainer.html)

The "Ranks" section of the ability editor: the highest rank of the ability and what each rank above the first changes on its numbers (cooldown, cost, cast time, range ...). The damage and healing of the effects of the ability read the rank in their own Amount (a part "Ability rank"), and an effect can need a rank (a requirement of the effect). See docs/systems/ability-ranks-and-item-generation.md, section 3.
