# OptionField

**Inherits:** [ConfigField](/advanced/editor/factory/config-field) < [HBoxContainer](https://docs.godotengine.org/en/stable/classes/class_hboxcontainer.html)

An enum (or int) property in a drop-down. Type the entries in the inspector, one for each choice, as `Name` (the value is its place in the list: 0, 1, 2) or `Name:value` when the values are not 0, 1, 2 (`Linear:0`, `ACES:3`). The entries are the labels the person sees, so write them as they should read.
