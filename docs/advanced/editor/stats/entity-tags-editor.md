# EntityTagsEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Entity Types Editor (the Entity Tag definitions): the types an entity can have (Humanoid, Beast, Undead ...). Conditions read them, so "+30 % damage against Undead" is a stat effect with the condition "opponent has tag Undead". See docs/systems/entity-stats.md, section 24.3.
