# GroupsEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Groups Editor: the groups effects, abilities and items can be in. A group decides how its members interact: how many effects of it can be active at once (Seals, Blessings, Elixirs, Well Fed), whether using one ability or consumable puts the others on cooldown (potions), and whether it is a slot on an item (enchants). See docs/systems/ability-mechanics-plan.md.
