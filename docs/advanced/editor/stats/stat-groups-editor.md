# StatGroupsEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Stat Groups Editor: the groups stats can be in (Primary, Secondary, Offensive, Defensive, Utility ...). A stat is put in groups in the Stat editor. A group lets one effect change all of its stats and decides the headings of the character sheet and of item tooltips. See docs/systems/entity-stats.md, section 27.
