# TriggerTagsEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Trigger Tags Editor: the tags a calculation can set on a hit (critical strike, dodge, block, multistrike, armor penetration). The name and description are the base editor's; everything else (kind, magnitude, what the magnitude does to the hit, animation, message, log phrase, the calculations it fires in) is shown by reflection of the definition. See docs/systems/entity-stats.md, section 24.1.
