# GrowthProfilesEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Growth Profiles Editor: how a kind of entity grows with its level (Heavy, Caster, Minion, Elite ...). The name, description and icon are the base editor's. The left column holds the parent profile and the chain the entity follows; the right column holds the growth entries (a stat or a pool and how it grows). A profile only lists what differs from its parent. See docs/systems/entity-stats.md, section 34.
