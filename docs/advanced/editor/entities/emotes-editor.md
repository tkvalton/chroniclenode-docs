# EmotesEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

The Emotes editor (the EmoteDefinition database): the commands a player types (/wave) and the library that the lines of NPCs, events and objects can pick from. An emote has a command, an animation, a sound, a target mode and one text for each way the line is read. See docs: Chat &gt; Emotes.
