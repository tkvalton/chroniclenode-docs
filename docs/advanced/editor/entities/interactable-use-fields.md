# InteractableUseFields

**Inherits:** [VBoxContainer](https://docs.godotengine.org/en/stable/classes/class_vboxcontainer.html)

The "Using it" fields of an interactable: what a user needs to use it (requirements, with a message and the choice to hide the prompt), how long using it takes (a time with a cast bar, and what interrupts it) and the animations while it is used (the user's, the object's). They work for every kind of interaction: a door, a chest, a gathering node.
