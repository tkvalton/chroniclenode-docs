# MountEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Mounts Editor: the mounts and vehicles of the game (Entities &gt; Mounts). A mount says how it moves, how the player steers it (a drive logic), and where riders sit (seats), with the abilities that each seat puts on the action bar. A Mount interaction on an NPC and the Mount effect point at one. The drive logics and the seats are classes: the editor lists the scripts it finds in data_classes/mount/drive_logic/ and data_classes/mount/seats/, so a class you add shows up here with its exported variables as fields. The name, description and icon are the base editor's.
