# KillExperienceEditor

**Inherits:** [VBoxContainer](https://docs.godotengine.org/en/stable/classes/class_vboxcontainer.html)

The editor of "Kill Experience Mode" in the Gameplay Config (Leveling): how much experience a defeated NPC gives. The mode is a choice of three; each shows only its own fields (nothing, a table of levels, or a formula). It writes straight to the config and tells the Gameplay Config editor to save. A small table at the bottom shows what the setting gives for a few levels, so it can be checked without playing.
