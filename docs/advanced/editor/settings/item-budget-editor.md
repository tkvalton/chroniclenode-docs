# ItemBudgetEditor

**Inherits:** [VBoxContainer](https://docs.godotengine.org/en/stable/classes/class_vboxcontainer.html)

The editor of "Item Budget Formula" in the Gameplay Config (General &gt; Item Generation): the formula that turns the item level into the stat budget of a generated item. Empty uses Linear 20. A small table shows what the setting gives for a few item levels, so it can be checked without playing. It writes straight to the config and tells the Gameplay Config editor to save. See docs/systems/ability-ranks-and-item-generation.md, section 5.
