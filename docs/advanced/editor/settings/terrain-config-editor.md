# TerrainConfigEditor

**Inherits:** [ConfigEditor](/advanced/editor/settings/config-editor) < [VBoxContainer](https://docs.godotengine.org/en/stable/classes/class_vboxcontainer.html)

The Terrain Settings tab (Game Settings): the TerrainConfig of the project. What is stored with the painting (slots per chunk, painting resolution, library texture size), the limits (the farthest the terrain is drawn, 16-bit painting) and what Low, Medium, High and Ultra terrain detail mean. The player's own choices (view distance, terrain detail) are in the Game Settings tab. See docs: Game Settings &gt; Terrain Settings.
