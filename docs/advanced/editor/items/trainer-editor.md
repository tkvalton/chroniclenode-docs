# TrainerEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Trainers Editor: the lessons that NPCs and objects teach (a TrainerInteraction points at one of these). A lesson teaches an ability, a rank, levels of a proficiency, a profession, a tier, a specialization, a recipe or any rewards, and has its own price and requirements. The name, description and icon are the base editor's. The left column holds the trainer's own settings (greeting, standing and prices); the right column holds the lessons. See docs/systems/skill-trainers.md, section 4.
