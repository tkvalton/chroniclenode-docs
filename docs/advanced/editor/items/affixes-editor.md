# AffixesEditor

**Inherits:** [ResourceEditor](/advanced/editor/base/resource-editor) < [Control](https://docs.godotengine.org/en/stable/classes/class_control.html)

Affixes Editor: the bonuses an item can roll ("Heavy", "of the Monkey", a silent +Crit). An affix says WHAT it brings (which stats, which effects); how much comes from the stat budget of the item. The name, description and icon are the base editor's. The left column holds the name, the roll and the filters; the right column holds the grants and a preview. See docs/systems/ability-ranks-and-item-generation.md, sections 5 and 6.
