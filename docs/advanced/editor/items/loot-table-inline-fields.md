# LootTableInlineFields

**Inherits:** [VBoxContainer](https://docs.godotengine.org/en/stable/classes/class_vboxcontainer.html)

A compact editor of one loot table, for the table a loot rule has of its own ("this guard carries the key"): the entries as rows (an item, a currency or another table, with its quantity, weight and chance), what always drops, what is rolled, and the number of rolls. The shared tables of the project are edited in Items &gt; Loot Tables. See docs/systems/ability-ranks-and-item-generation.md, section 8.
