# Advanced

The advanced section is for developers who read and write scripts. It explains how ChronicleNode is built, and how to extend it with your own effects, triggers, actions, formulas and more.

You do not need it to make a game: everything in [Basic](/basic/) works without code.

This section grows as chapters are written. It is organised the same way as the basic guide: a chapter for each system, with the classes behind it, how it runs, the signals it emits, and worked examples of extending it.
