# VehicleInteraction

**Inherits:** [MountInteraction](/advanced/entities/interactions/mount-interaction) < [EntityInteraction](/advanced/entities/interactions/entity-interaction) < [Interaction](/advanced/entities/interactions/interaction) < [Resource](https://docs.godotengine.org/en/stable/classes/class_resource.html)

Lets the player get into this vehicle: a cart, a tank, a boat. It is a Mount interaction that is steered with the Vehicle steering (throttle and brake, turning that grows with the speed) by default. Give the vehicle a model with a mount seat where the driver sits (a model that is a plain mesh works too: use the Seat offset). Movement Boat makes it float on the water of a movement volume.

## Description

An enemy vehicle (a tank) needs no rider: it is a normal NPC and fights with its own AI.
