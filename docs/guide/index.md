# About the guide

The guide describes every part of the ChronicleNode editor, one chapter for each category in the editor's drop-down: what the part is for, what every field does, and how it behaves in the game.

Each chapter starts with an overview page that explains the idea and how the pieces fit together, followed by a page for each editor in the category. The overview is the place to start.
